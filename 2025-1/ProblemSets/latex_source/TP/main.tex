\section*{Background}
Federated Learning (FL) keeps training data on client devices and shares only gradients
\(\mathbf g = \nabla_{\boldsymbol\theta}\mathcal L\bigl(f_{\boldsymbol\theta}(\mathbf x),y\bigr)\).
Yet, \emph{gradient inversion} can reconstruct \((\mathbf x,y)\) from \(\mathbf g\) and the current model
\(f_{\boldsymbol\theta}\)~\cite{zhu2019dlg,zhu2020idlg,zhu2024dlgfb,guo2025survey}.

\section*{Optimization Problem}
Given:
\begin{itemize}[nosep]
  \item model parameters \(\boldsymbol\theta\) (2-layer MLP, trained on MNIST);
  \item a leaked gradient vector \(\mathbf g^\star\) from a \emph{single} unknown sample.
\end{itemize}
Recover an image \(\hat{\mathbf x}\!\in[0,1]^{28\times28}\) and label
\(\hat y\!\in\!\{0,\dots,9\}\) by minimizing
\[
\min_{\mathbf x\in[0,1]^{784},\,y\in\{0,\dots,9\}}
\Bigl\lVert
\nabla_{\boldsymbol\theta}\mathcal L\bigl(f_{\boldsymbol\theta}(\mathbf x),y\bigr)
-\mathbf g^\star
\Bigr\rVert_2^2
+\lambda\|\mathbf x\|_2^2 .
\]

\section*{Tasks}
\begin{enumerate}[label=\textbf{\arabic*.}, nosep]
  \item Implement L-BFGS, Adam, or both, to optimize \(\mathbf x\) (continuous) and \(y\)
        (use one-hot logits or the iDLG pseudo-label trick).
  \item Run at least five random initializations and keep the best solution.
  \item Plot objective value over iterations and pixel MSE versus ground truth
        (provided for grading).
  \item Study sensitivity to \(\lambda\) and optimizer hyper-parameters.
\end{enumerate}

\section*{Starter Code (PyTorch)}
All necessary functions are provided in \url{https://github.com/rcpsilva/BCC405-PCC179_NonLinearOptimization/blob/main/2025-1/ProblemSets/latex_source/TP/starter.py}. The script is well-commented to help you understand how to:

\begin{itemize}[nosep]
  \item Load and train a 2-layer MLP on MNIST.
  \item Simulate gradient leakage from a single or batched input.
  \item Reconstruct inputs by minimizing gradient difference.
  \item Visualize both the reconstructed image and optimization trajectory.
\end{itemize}

\textbf{Usage:} run \texttt{starter.py} directly:
\begin{lstlisting}[language=bash]
python starter.py
\end{lstlisting}

This will:
\begin{enumerate}[nosep]
  \item Train a 2-layer MLP briefly on MNIST.
  \item Simulate gradient leakage from a randomly selected image.
  \item Reconstruct both a single image and a small batch.
  \item Plot the reconstruction and the optimization loss over time.
\end{enumerate}

You are encouraged to modify:
\begin{itemize}[nosep]
  \item The optimizer (e.g., try Adam instead of L-BFGS);
  \item The regularization parameter \(\lambda\);
  \item The number of restarts, learning rates, and initialization strategies.
\end{itemize}

\textbf{Functions available in \texttt{starter.py}:}
\begin{lstlisting}[language=Python]
train_model(...)          # trains MLP
sample_single(...)        # draws one MNIST sample
sample_batch(...)         # draws a batch of samples
compute_gradient(...)     # computes gradient of loss wrt parameters
reconstruct_single(...)   # reconstructs image+label from a single g_star
reconstruct_batch(...)    # reconstructs batch from g_star
plot_reconstruction(...)  # shows ground truth vs. reconstructed image
plot_loss(...)            # plots optimization trajectory
\end{lstlisting}

\section*{Hints}
\begin{itemize}[nosep]
  \item Normalise \(\mathbf g^\star\) and use gradient clipping.
  \item Use multiple restarts—the landscape has many poor local minima.
  \item TV-loss or generative priors (GAN latents) can refine images but enlarge the search space.
\end{itemize}
